# felukka.org

Landing page for Felukka and its products (Koptan, Koptan UI, Helm charts). Built with [Astro Starlight](https://starlight.astro.build); the theme reuses the Koptan UI tokens.

```bash
npm install
npm run dev     # http://localhost:4321
npm run build   # static site in dist/
```

Pushes to `main` deploy to GitHub Pages (`.github/workflows/deploy.yaml`).
